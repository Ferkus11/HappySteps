# Казахский глоссарий интерфейса

Единые термины для `src/messages/kk/*.json`. Современный казахский (кириллица), без ё/щ/ъ.
Пользовательский контент (имена, названия групп и кружков, блюда, тексты объявлений и сообщений) не переводится.

## Дни и месяцы

Месяцы и дни недели берутся из файлов переводов (браузер для kk подставляет русские названия).

- Месяцы: қаңтар, ақпан, наурыз, сәуір, мамыр, маусым, шілде, тамыз, қыркүйек, қазан, қараша, желтоқсан.
  В заголовке — «2026 ж. қазан», во фразе — «2026 жылғы қазан».
- Дни недели: дүйсенбі, сейсенбі, сәрсенбі, бейсенбі, жұма, сенбі, жексенбі.
  Сокращения: Дс, Сс, Ср, Бс, Жм, Сн, Жс (везде одинаковые).

## Грамматика сообщений

- ICU-плюралы в kk — `one`/`other` с одинаковой формой: существительное после числа стоит в единственном числе
  («{count, plural, one {# бала} other {# бала}}»).
- Порядок слов казахский: «{total} ішінен {marked}», «{date} дейін», «{year} ж. {month}».
- Падежные окончания к значениям не приклеиваются (имя группы может кончаться на любую букву): «„{group}" тобында».
- Повелительное наклонение — вежливое на «-ңыз/-ңіз»: «Қайталап көріңіз», «Таңдаңыз».
