## Этап 0 — каркас
- Next.js 16 (App Router, TS strict), Tailwind v4, UI-кит в стиле shadcn/ui, lucide-react.
- Дизайн-токены Happy Steps (CSS-переменные, акцент настраивается), Manrope с казахской кириллицей.
- i18n ru/kk (next-intl), переключение без перезагрузки; тесты полноты переводов.
- Оболочка: сайдбар + шапка на десктопе, нижняя панель 4 пункта + «Ещё» на телефоне; баннер «Нет подключения».
- Локальный Supabase без Docker (`npm run db:start`), `supabase/config.toml` для Docker-варианта.
- Тесты: Vitest (unit, RLS), Playwright (e2e на standalone-сборке, скриншоты 390/1440), CI в `.github/workflows/ci.yml`.
- Проверочный цикл: `npm run verify`; скриншоты: `npm run screens` → `screenshots/`.

## Этап 1 — фундамент
- Схема: сады, настройки, тарифы/подписки, профили, членства (несколько ролей и садов), приглашения, группы,
  воспитатели групп, дети, родители, история групп, журнал действий, попытки входа. RLS на всех таблицах.
- SQL-хелперы прав: `has_role`, `is_admin`, `is_staff`, `teaches_group`, `is_guardian`, `can_manage_role` (§3.3),
  `child_visible`, `kitchen_allergies` (повар видит только аллергии), `transfer_child/transfer_group` (история по датам).
- Триггеры: нельзя архивировать последнего владельца; заведующая не меняет реквизиты/согласие/часовой пояс;
  нельзя удалить группу с активными детьми; авто-архив родителя, когда все его дети в архиве; запрет межсадовых связей.
- Вход по телефону + пароль (техн. e-mail), лимит 5 неудачных попыток за 15 минут; приглашения и сброс пароля —
  одноразовые ссылки на 72 часа с кнопками «Скопировать» и «Отправить в WhatsApp» (текст на языке сада).
- Дубли номеров: человек добавляется в сад без нового аккаунта, с сообщением администратору.
- Согласие на обработку данных при первом входе (текст из настроек сада), экраны «Доступ приостановлен» и «Доступ закрыт».
- Переключатель сада/роли в меню аккаунта, выбор запоминается (cookie + профиль).
- Суперадмин: список садов, создание сада и владельца, блокировка, тариф и срок подписки. Проверка подписки — `lib/subscription.ts`.
- Сотрудники (добавление по ролям, архив/восстановление, сброс пароля, удаление навсегда с вводом названия сада, группы воспитателя),
  группы (заполненность, цвета, перевод всей группы), дети (карточка, перевод с датой, архив с причиной, фото, родители, отвязка),
  журнал действий с фильтрами, настройки сада (владелец / заведующая), профиль, поиск.
- Тесты: 27 RLS-тестов (изоляция садов по всем таблицам с `kindergarten_id` автоматически, видимость по ролям, архив, блокировка),
  e2e сценарии 1, 9 (часть: вход архивного), 10, 11 + дубли и лимит входа.

## Этап 2 — ежедневные операции ✅
- Общая основа: праздники и выходные сада (автозаполнение праздников РК), уведомления `notify()`, реестр виджетов главной,
  защита cron через `CRON_SECRET`, параллельные локальные стенды, локальная эмуляция Realtime.
- **Учёт рабочего времени:** кнопка «Начать/Закончить рабочий день», графики по дням недели, исключения на дату, отсутствия,
  4 плитки статусов у заведующей, ручные правки с комментарием и журналом, автозакрытие (cron), табель за месяц с экспортом .xlsx и .pdf.
- **Посещаемость:** отметка «Был / Не был» и «Все пришли», пропуски от родителей (дата/период, причина, отмена),
  правка прошлых дней только администрацией с журналом, напоминания 10:00/11:00 (cron), порции для повара, отчёт за месяц с .xlsx.
- **Меню:** приёмы пищи из настроек, редактор с клавиатуры, «Скопировать с другого дня», меню на сегодня/завтра, аллергии у повара.
- **Объявления:** аудитории (весь сад / группы / сотрудники), фото и PDF, «Важное», прочтения «N из M», «Напомнить».
- **События:** месячный календарь и «Ближайшие», дни рождения по ролям, праздники сада, напоминание накануне (cron).
- Главные по ролям собраны из виджетов модулей.
- Ревью этапа: исправлены права (дни рождения, служебные поля, файлы объявлений), выходные, перегруженная карточка сотрудника.
- Тесты: unit 60, RLS 83, e2e 36 (сценарии 2, 3, 4, часть 9 — табель архивного сотрудника), скриншоты `screenshots/stage2/`.
